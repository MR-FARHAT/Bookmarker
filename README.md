# Bookmarker

> This project was an assignment (task) from the Front-End Development diploma I studied at **Route Academy**. It's kept here only to document my learning, not as a production app.

**Live demo:** https://mr-farhat.github.io/Bookmarker/

A small app to save your favourite websites. Add a site name and URL, open it with one click, or delete it. Bookmarks are kept in the browser with `localStorage`, so they're still there after a refresh.

## What I practiced

- DOM manipulation and rendering a list from an array
- Form validation with a regular expression for URLs
- Saving and loading data with `localStorage`
- Escaping user input before rendering it

**Built with:** HTML, CSS, JavaScript, Bootstrap 5, Typed.js
